1. Overview of the module
This module provides two simple pricing utility functions:

calculateDiscount(price, discountPercent) calculates the final price after applying a percentage discount.
applyTax(amount, taxRate) calculates the final amount after applying a percentage tax rate.
These functions are useful in shopping carts, invoices, checkout flows, billing systems, and financial calculations where percentage-based adjustments are needed.

4. Edge cases & warnings
calculateDiscount
Negative price values are rejected.
Negative discountPercent values are rejected.
A discountPercent of 0 returns the original price.
A discountPercent of 100 returns 0.
A discountPercent greater than 100 returns a negative final price.
Example:

javascript
console.log(calculateDiscount(100, 150)); // -50
This behavior is allowed by the current implementation.

applyTax
The function does not validate input.
Negative amount values are accepted.
Negative taxRate values are accepted and effectively reduce the amount.
A taxRate of 0 returns the original amount.
Very large tax rates can significantly increase the result.
Non-number values may produce unexpected results due to JavaScript type coercion.
Example:

javascript
console.log(applyTax(100, -10)); // 90

5. Best practices notes
Validate inputs before calling these functions, especially in production payment or billing flows.
Use numeric values only. Avoid passing strings such as "100" or "10".
Consider rounding final monetary values to the correct currency precision at the application boundary.
Be explicit about whether discounts greater than 100% are allowed.
Be consistent with validation rules between calculateDiscount() and applyTax().
For financial systems requiring exact precision, consider integer minor units such as cents instead of floating-point decimal amounts.
